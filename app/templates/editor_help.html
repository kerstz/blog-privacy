Text Editor Help (BBCode)

Comments, replies and posts use BBCode. Raw HTML in comments is never executed: everything is escaped and sanitized on the server.

Formatting

[b]Bold text[/b]

Makes text bold

[i]Italic text[/i]

Makes text italic

[u]Underlined text[/u]

Underlines text

[s]Struck text[/s]

Strikes through text

Links and images

[url]https://example.com[/url]

Link to a URL

[url=https://example.com]Link text[/url]

Link with custom text

[img]/uploads/image.webp[/img]

Image hosted on this blog

[img=400,300]/uploads/image.webp[/img]

Image with a maximum width / height (px)

[img]https://example.com/a.jpg[/img]

External images are shown as a link, never loaded: loading them would reveal every reader's IP address to that site

Lists and blocks

[list]
[*]Item 1
[*]Item 2
[/list]

Bulleted list

[list=1]
[*]Item 1
[*]Item 2
[/list]

Numbered list

[quote]Quotation[/quote]

Quote block

[code]Source code[/code]

Code block

Colors and sizes

[color=red]Red text[/color]

Text color (name or #hex)

[size=18]Bigger text[/size]

Text size in pixels (8 to 48)

Alignment

[center]Centered[/center]

Centers the text

[left]Left[/left]

Aligns left

[right]Right[/right]

Aligns right

[justify]Justified[/justify]

Justifies the text

Full example

[b]Bold title[/b]
[i]Italic paragraph[/i]
[list]
[*]First point
[*]Second point
[/list]
[quote]Important quote[/quote]
[url=https://example.com]Link to a site[/url]

Tip: tags can be combined.

Privacy: this blog never loads third-party content, so external images appear as links.
